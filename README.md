# 歴代首相★恋の議事録

[ブラウザで遊ぶ（GitHub Pages）](https://afrotty07.github.io/20260125sorirenai/) · ログイン不要

明治・大正の24内閣をめぐる、５章構成の恋愛アドベンチャー。既存の人物イラスト・会話とBGMを使用しています。人物像・会話・イベント・結末は創作です。相性の評価は史実や政策の正誤を示しません。

音楽：[魔王魂「ピアノ26」](https://maou.audio/bgm_piano26/)

## 起動

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

```sh
npm test       # ゲーム進行・結末到達性・セーブ互換性の検証
npm run build # dist/ に製品版を出力
npm run preview
```

## 遊び方

1. 内閣ごとの24ルートから１つを選びます。
2. 毎章、面会の前に１回だけ準備できます。本音を聞くと恋心＋8と相性ヒント、世間の声を調べると世論＋8。行動力を１使います。休憩すると行動力＋2（最大5）。
3. 会話で恋心と世論が変わります。選択肢の位置は周回・章ごとに変わります。「想いを込める」は行動力２を消費し、恋心＋6・世論＋4を上乗せします。
4. 第２章・第４章のあとに、４種類から重複しない２つの突発イベントが発生します。イベントでは変化量が先に表示されます。行動力が足りない選択はできません。
5. 第５章を終えると、４種類の結末のいずれかへ。会話の選択は数字1〜3、返事のあとにはEnterでも進められます。

| 結末                            | 条件（上から優先）     |
| ------------------------------- | ---------------------- |
| 恋も、未来も。 / TRUE END       | 恋心80以上・世論65以上 |
| ふたりだけの約束 / LOVE END     | 恋心70以上             |
| 最高の相棒 / PARTNER END        | 世論65以上             |
| また、別の歴史で / FAREWELL END | 上記以外               |

「思い出手帖」には24ルート×４種類＝96の結末枠と、５つの実績があります。同じ人物の再任内閣も別ルートとして記録します。「議事録」では今回の選択と結果を振り返れます。

## 表情差分

15種類の既存原画それぞれに「微笑み・照れ・真剣・落胆」の４表情、計60表情を追加しました。原画が同一の再任内閣は共通の差分を使い、24ルートすべてに対応します。第８代と第17代の大隈重信は原画が異なるため、別々の差分を保持しています。

- 会話の反応、関係の深まり、想いを込める操作、イベント、結末に連動して表情が切り替わります。
- 内閣選択の「表情差分を見る」や、プレイ中の「表情を見る」から、４つの表情を見比べられます。
- スプライトシートを１枚だけ読み込み、ブラウザ内で該当フレームを表示します。表情ごとの通信を待つ必要はありません。読み込み中・失敗時は元の絵を表示します。
- 反応の表情も途中データに保存します。上限100で恋心が増えなくても、嬉しい返事では嬉しい表情を保ちます。
- 元の画像は上書きしていません。追加画像は `public/assets/pms/expressions/`、使用した生成ツール・参照原画・プロンプトは `docs/portrait-generation.json` に保存しています。

## セーブ

- 操作ごとにローカル保存。タイトルに戻ったり再読み込みしても、会話・準備・イベント・返事の途中から再開できます。
- 新しい物語で途中データを置き換える場合は確認を表示します。読了記録は残ります。
- 旧版の途中データは同じ章の準備から再開。旧版の人物名ベースのクリア記録は、手帖に別途表示します。
- 既存のFirebaseプロジェクトを引き続き使用。Googleログイン後にクラウドの記録を取得・統合してから、新しい形式の記録・途中データを保存します。旧クラウド項目は保持します。接続失敗時もローカルでは遊べます。
- 複数端末での同時進行は最後のクラウド保存が優先されます。

## 検証

`npm test` は24ルート×12通りのイベント組み合わせすべてについて、合法な操作による４つの結末への到達を検証します。結末の境界、行動力の制約、連打の重複防止、イベント位置、セーブの検証、旧形式の移行も確認します。

実ブラウザではエンディングまでの操作、途中の再読み込み・復帰、手帖への登録とモーダル操作、スマートフォン幅での表示を確認します。Googleログインとクラウドへの実際の書き込みは、ユーザーのログイン操作が必要なためローカル検証には含みません。

主要ファイル：`src/lib/game.js`（ルール・イベント）、`src/lib/storage.js`（セーブ）、`src/App.jsx`（画面）、`src/index.css`（表示）、`src/data/pmData.js`（既存の物語データ）。
